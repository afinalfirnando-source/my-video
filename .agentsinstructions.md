# 🤖 AI Agent Instructions for Remotion Stock Video Production

## Project Structure
```
src/
  templates/
    cinematic-space/index.tsx  → CinematicSpace (4K 60fps 12s)
    cinematic-space/types.ts   → Props schema
    stock-lowerc-third/index.tsx → LowerThird (4K 30fps)
    stock-lowerc-third/types.ts  → Props schema + Zod validation
  Root.tsx → Composition registrations (both templates)
```

## Compositions
| ID | Resolution | FPS | Duration | Codec Default |
|---|---|---|---|---|
| `LowerThird` | 3840×2160 | 30 | 60 frames | ProRes |
| `CinematicSpace` | 3840×2160 | 60 | 720 frames | ProRes |

## How to Create a New Template (AI Instructions)
1. Create `src/templates/<name>/index.tsx` + `types.ts`
2. Register in `src/Root.tsx` with `<Composition>`
3. Run `npx tsc --noEmit` to verify
4. Studio auto-reloads at localhost:3000

## Render Commands
- **Quick render**: `npx remotion render <CompositionID> out/video.mov --codec=prores`
- **H.264 for social**: `--codec=h264 --out-name=video.mp4`
- **Test render (fast)**: `--frames=0-59 --width=1280 --height=720`

## AI Prompt Format
Use slash commands from installed Remotion Agent Skills:
- `/remotion-create` — Create new template
- `/remotion-markup` — Edit existing template markup
- `/remotion-render` — Render and save
- `/remotion-best-practices` — Full project guidance
